Module 1: Dimensionality Reduction & Bias/Variance

Syllabus Module 1
  • PCA 2D Projection: Unsupervised linear dimensionality reduction projecting 16 handcrafted features into a 2D plane capturing >57% variance.
  • Variance Reduction via Bagging: Individual decision trees have low bias but high variance; Random Forest aggregates 100 de-correlated trees to achieve low bias and minimal variance.
  • Out-of-Bag (OOB) Estimation: Evaluates generalization capability without requiring an independent validation partition.

Module 2: Learning with Trees (Random Forest)

Syllabus Module 2
  • Ensemble Bagging: Combines bootstrap sampling of data with random feature subspace selection at each split.
  • Gini Impurity Splitting: Each internal node selects the handcrafted feature minimizing class impurity: $I_G = 1 - \sum p_i^2$.
  • Feature Importance: Measures aggregate reduction in Gini Impurity brought by each feature across all 100 trees.
